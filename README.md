# 👩‍💻 Ankita Behera — Personal Portfolio

A modern, responsive personal portfolio website showcasing my **skills, AI/ML projects, certifications, education, and professional profile**. The portfolio is designed to present my work and technical journey with a clean, interactive, and visually polished user experience.

Built using **HTML5, CSS3, and Vanilla JavaScript**, with responsive layouts, animated interactions, dynamic certification cards, and a modern glassmorphism-inspired interface.

## ⚙️ Core JavaScript Functionality

The portfolio uses Vanilla JavaScript to provide interactive functionality without relying on a frontend framework.

The main JavaScript functionality includes:

* Certification carousel navigation
* Certificate modal/lightbox interaction
* Scroll-reveal animations
* Active navigation tracking
* Mobile navigation drawer
* Smooth scrolling
* Interactive UI elements

The certification section is data-driven, allowing certificate information to be maintained inside the JavaScript data structure and rendered dynamically.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ankitabehera888/ANKITA_BEHERA_PORTFOLIO.git
```

### 2. Navigate to the Project

```bash
cd ANKITA_BEHERA_PORTFOLIO
```

### 3. Run the Website

Since this is a static HTML/CSS/JavaScript project, no package installation or backend server is required.

You can either:

**Option 1 — Open directly**

Open:

```text
index.html
```

in your browser.

**Option 2 — Use VS Code Live Server**

Open the project in VS Code and launch `index.html` using the **Live Server** extension.
